# GMP residential burglary draft

All analysis is offline. The notebook executes from the compact public extract;
original XLSX files are optional for re-extraction and must stay outside version control.
No source-cache files are part of this deliverable. No commit or push is authorised.

From the checkout root, using its existing environment without dependency resolution:

```bash
OPENBLAS_NUM_THREADS=1 UV_CACHE_DIR=/tmp/gmp-uv-cache uv run --offline --no-sync --python .venv/bin/python posts/gmp-burglary-outcomes/extract.py source-cache
OPENBLAS_NUM_THREADS=1 UV_CACHE_DIR=/tmp/gmp-uv-cache uv run --offline --no-sync --python .venv/bin/python posts/gmp-burglary-outcomes/analysis.py
OPENBLAS_NUM_THREADS=1 UV_CACHE_DIR=/tmp/gmp-uv-cache uv run --offline --no-sync --python .venv/bin/python -m unittest discover -s posts/gmp-burglary-outcomes -p test_analysis.py -v
OPENBLAS_NUM_THREADS=1 UV_CACHE_DIR=/tmp/gmp-uv-cache uv run --offline --no-sync --python .venv/bin/python posts/gmp-burglary-outcomes/build_notebook.py
OPENBLAS_NUM_THREADS=1 UV_CACHE_DIR=/tmp/gmp-uv-cache uv run --offline --no-sync --python .venv/bin/python posts/gmp-burglary-outcomes/execute.py
```

`--no-sync` is necessary: ordinary `uv run --offline` tries to reconcile the repository's lockfile and requests wheels not cached locally. No installations are required.

- `data/burglary_raw.csv.gz`: lossless public burglary-row extract, including other burglary classes, raw missing tokens and the unused outcome-flow column.
- `data/manifest.json`: all 13 source filenames, hashes, sizes, worksheet headers, financial coverage and workbook update text. Attachment URLs were checked against the Home Office collection page and are recorded in the manifest and source_urls.json.
- `data/workbook_notes.json`: full text of workbook Notes sheets.
- `data/codebook.csv`, `outcome_codes.csv`: source-specific observed coding.
- `data/panel.csv`: force-quarter data, preserved missing values, explicit GMP recording warnings; domestic years precede the comparable residential series.
- `data/out_of_era.csv`: residual older residential codes after April 2023, included in the primary residential total.
- `data/benchmarks.csv`: available-force weighted territorial national and metropolitan benchmarks; contributor counts expose coverage.
- `data/quality_benchmark.csv`: territorial benchmark with the model's source-warning exclusions.
- `data/negative_cells.csv`: actual signed negative source cells, never clipped to zero.
- `data/gmp_audit.csv`: every GMP quarter, including missing and flagged quarters.
- `data/period_summary.csv`: raw denominators, charges, unresolved counts and aggregate rates.
- `data/specifications.csv`, `weights.csv`, `donor_exclusions.csv`: model fits, holdout diagnostics and eligibility decisions.
- `data/synthetic_series.csv`: quarterly raw fit/gap; do not interpret across the flagged recording year.
- `data/leave_one_donor_out.csv`, `placebos.csv`, `post_window_sensitivity.csv`: actual sensitivity results.
- `data/results.json`: machine-readable headline diagnostics.
- `figures/`: dark and light PNGs generated by the executed notebook.

Earlier blog: https://andreasthinks.me/posts/burglary_attendance/

Source data are Crown copyright, available under the Open Government Licence v3.0:
https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/

The source notes, rather than uncached web pages, supplied the inspected definitions.
No consistent-age archived cohort snapshots were available. The model fails its
recording-continuity gate and has no causal interpretation. See the notebook and
GMP_HANDOFF.txt for actual results, limitations and render validation.

Execution method: `execute.py` uses IPython InteractiveShell in-process, captures
real rich displays and stdout/stderr, and fails on any cell error. Standard nbclient
kernel execution was attempted, but the sandbox rejects ZMQ socket binding,
including Unix-domain sockets. No kernel outputs were fabricated or substituted.
